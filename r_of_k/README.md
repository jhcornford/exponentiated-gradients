# r_of_k

Single point-neuron sparse-input experiments (Fig 4B). Run scripts from inside `r_of_k/`.

- `train.py`: training loop
- `r_of_k_data.py`: task data
- `run_sweeps.sh`: runs the EG and GD lr sweeps `conf/sweep/mlp_gd.yaml` and `mlp_eg.yaml`  
-  `analysis/sparse_inputs_rofk.ipynb` plots results
